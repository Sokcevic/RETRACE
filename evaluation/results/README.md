# Results behind the paper

Outputs of the scripts in `evaluation/scripts`, as reported in the paper. They hold aggregate
scores, per-question scores and question ids only, no document text.

| File | Paper | Produced by |
|---|---|---|
| `structure_analysis.json` | Table 1 (corpora), RQ1 (QASPER heading recall/precision) | `analyze_structure.py` |
| `methods_<ds>.json` (`_mineru`: MinerU input) | Table 2 (retrieval), RQ4 unit size and heading paths | `eval_methods.py` |
| `qa_methods_<ds>_qwen3-32b.json` | Table 3 (answers), with `per_item` scores and bootstrap tests | `eval_qa_methods.py` |
| `xref_join.json`, `xref_join_mineru.json` | RQ4 cross-references | `xref_join.py` |
| `links_adn.json`, `links_obliqa.json` | RQ4 links ablation | `eval_links.py` |

`qa_methods_qasper_qwen3-32b.json` and `methods_qasper.json` use PyMuPDF input (265 locatable
questions); the paper reports the MinerU variants (309 questions).
Per-query retrieval values (`methods_<ds>.pkl`) are regenerated by `eval_methods.py`.
